# کارنما

از پوشه `frontend`، با `npm install` وابستگی‌ها را نصب و با `npm run dev` برنامه را اجرا کنید. آزمون‌ها با `npm test` و `npm run test:e2e` اجرا می‌شوند.

برای انتشار، محتویات پروژه را در مخزن `kanban-test` روی شاخه `main` قرار دهید و در تنظیمات مخزن، بخش **Pages > Build and deployment > Source** را روی **GitHub Actions** بگذارید. پس از هر push به `main`، سایت به‌صورت خودکار در `https://USERNAME.github.io/kanban-test/` منتشر می‌شود؛ `USERNAME` را با نام کاربری GitHub جایگزین کنید.
